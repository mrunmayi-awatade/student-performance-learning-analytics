# Student Performance & Learning Analytics

## Overview
This project analyzes student academic performance using Python and data science techniques. It explores study hours, attendance, subject-wise marks, and performance categories.

## Objectives
- Clean and prepare student data
- Analyze attendance and academic performance
- Compare subject-wise marks
- Visualize relationships between variables
- Explore correlations between numerical features
- Build and evaluate a basic Linear Regression model

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Create and explore the student dataset
2. Handle missing values and duplicate records
3. Calculate total and average marks
4. Categorize student performance
5. Perform descriptive and exploratory data analysis
6. Analyze attendance and subject-wise performance
7. Create visualizations and a correlation heatmap
8. Train and evaluate a Linear Regression model
9. Export the cleaned dataset and analysis report

## Files Included
- `student_performance_learning_analytics.ipynb`
- `cleaned_student_performance.csv`
- `student_performance_report.txt`

## Dataset
The project uses synthetic sample student data for demonstration and learning purposes.

## Important Note
The prediction model is educational and has not been validated for real-world student assessment. Model results should be interpreted cautiously.

## Outcome
Gained practical experience in data cleaning, exploratory data analysis, visualization, correlation analysis, basic predictive modeling, and report generation.
